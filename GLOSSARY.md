# Glossary

Use these terms in the UI, the code, the JSON schema and the docs. Do not use other names for them.

| Term                       | Meaning                                                                                                                                                                                                          | Do not use                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| **Plan**                   | One plan for a project. It contains stages, tasks, milestones, bands, remarks and the header and footer fields.                                                                                                  | project, document, board      |
| **Stage**                  | A group of tasks in a plan. A stage has a title, a description and a color.                                                                                                                                      | phase, section                |
| **Task**                   | A work entry with no parent (level 1).                                                                                                                                                                           | activity, item                |
| **Subtask**                | A task with a parent (level 2). A subtask cannot have subtasks.                                                                                                                                                  | child item, sub-item          |
| **Parent**                 | A task that has one or more subtasks.                                                                                                                                                                            | group                         |
| **Leaf**                   | A task without subtasks, or a subtask. Only a leaf has a status that the user sets.                                                                                                                              | child, atomic task            |
| **Finished**               | The status done or canceled. Only a finished task satisfies a dependency.                                                                                                                                        |                               |
| **Ready**                  | A leaf with status `todo` whose effective dependencies are all finished. A leaf with no effective dependencies is ready. A parent is ready when its derived status is `todo` and one or more subtasks are ready. | unblocked, greenlit           |
| **Blocked**                | A leaf with status `todo` that has an effective dependency that is not finished. A parent is blocked when its derived status is `todo` and no subtask is ready.                                                  | waiting                       |
| **Derived value**          | A value that the app calculates from other data. The user cannot edit it directly.                                                                                                                               | computed field                |
| **Planned window**         | The stored date range of a parent. It includes the subtask dates and can be wider. It grows with the subtasks. Edit the parent to reduce it within the subtask limits.                                           | Fallback value                |
| **Own dependencies**       | The ids in the `dependsOn` field of a task or subtask.                                                                                                                                                           |                               |
| **Effective dependencies** | For a subtask: its own dependencies and the own dependencies of its parent. For a task, with or without subtasks: its own dependencies.                                                                          |                               |
| **Date rule**              | A cannot be a dependency of B if `A.start > B.end`.                                                                                                                                                              |                               |
| **Ready light**            | A small green dot. It shows that a task is ready.                                                                                                                                                                | status, traffic light         |
| **Task dialog**            | The dialog with all fields of a task or subtask. Its UI title is "Task details" ("Subtask details").                                                                                                             | task modal, modal             |
| **Move**                   | A change of the stage or the parent of a task or subtask.                                                                                                                                                        |                               |
| **Move-conflict dialog**   | The dialog that lists the changes that a move needs before it can occur.                                                                                                                                         |                               |
| **Milestone**              | A dated event in the plan. Labels M1 … Mn follow date order.                                                                                                                                                     |                               |
| **Band**                   | A titled time range that shows as a tint behind the Gantt task lines.                                                                                                                                            | annotated range, period       |
| **Task line**              | The stage-colored line that shows the date range of a task in the Gantt.                                                                                                                                         | Gantt bar                     |
| **Station dot**            | A dot at a visible task-line end or at a single date. Its fill form shows task status.                                                                                                                           | task dot                      |
| **Connector**              | A line from a predecessor end port to a dependent start port. It has no arrowhead.                                                                                                                               | dependency line, arrow        |
| **Linked highlight**       | The immediate highlight of a Gantt label cell and its Work plan row. Gantt row hover (label or band), Work plan hover or focus, or Gantt line focus sets it. A pinned Timeline scrolls to show the task line.    |                               |
| **Route focus**            | The visual emphasis on a task and its upstream and downstream dependencies. Other task marks dim on screen, also for an isolated task. A collapsed parent combines its own route and its hidden subtask routes.  | route highlight, path focus   |
| **Lit overlay**            | A decorative full-ink path for a noncycle connector on the focused route. It lies above base connectors and below cycle connectors. It has a separate ground casing.                                             | selected connector            |
| **Junction ring**          | A ground-filled ring where connector paths join or branch along a continuing riser.                                                                                                                              | junction dot                  |
| **Tap**                    | The sign where a clamped connector riser leaves from under its source task line.                                                                                                                                 | source junction               |
| **Stage badge**            | The stage-color label S1, S2 and so on.                                                                                                                                                                          | stage chip                    |
| **Stage rule**             | The 2 px stage-color line below a stage heading.                                                                                                                                                                 | colored band                  |
| **Continuation stub**      | A 4 px connector segment with a 2 px cross tick at a Gantt sheet break. Paired stubs share a riser position.                                                                                                     | continuation arrow            |
| **Remark section**         | A titled list of bullets at the end of the plan. The short form "section" is approved in UI strings that are about a remark section.                                                                             | note section                  |
| **Mention**                | A token `@[task:<id>]` in a note. The app shows it with the current task title.                                                                                                                                  |                               |
| **Workspace**              | The screen layout with controls to edit a plan.                                                                                                                                                                  | editor                        |
| **Preview**                | The read-only screen layout that shows the paginated sheets.                                                                                                                                                     | print view                    |
| **Sheet**                  | One printed page (A4 or US Letter).                                                                                                                                                                              |                               |
| **Bottom sheet**           | A modal menu panel at the bottom edge of the window. The menus use it when the primary pointer is coarse. It is not a printed sheet.                                                                             | drawer, sheet (for the menus) |
| **Paginator**              | The code that puts blocks on sheets.                                                                                                                                                                             |                               |
| **Viewer state**           | Settings for one browser only. They are not in the plan file.                                                                                                                                                    | user settings                 |
| **UI language**            | The language of the app controls, the date formats and the printed labels. Part of the viewer state. A plan has no language.                                                                                     |                               |
| **Cycle warning**          | A warning on a dependency that is part of a cycle in the effective dependencies. The app permits cycles.                                                                                                         | cycle error                   |
| **Commit**                 | The end of one edit: blur, Enter, a status selection, a picker, a dialog action. One commit is one undo step.                                                                                                    |                               |

## Rules for UI text

- A menu item that opens a dialog ends with “…”. Toolbar and icon buttons do not.
